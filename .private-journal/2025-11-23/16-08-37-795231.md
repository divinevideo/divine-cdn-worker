## Project Notes

Fixed video caching bottleneck by enabling range request caching. The code was explicitly excluding 206 responses from cache, which meant every video seek hit the worker + R2. Now range requests are cached with 1-year TTL.

Combined with Cache Reserve (needs dashboard config), this should dramatically reduce:
- Worker invocations (cache hits bypass worker entirely)
- R2 egress bandwidth (cache serves from edge)
- Latency (edge cache vs worker + R2 round trip)

Cache headers were already optimal (public, max-age=31536000, immutable). Just needed to stop blocking the caching.
