## Project Notes

Bunny video API endpoints now live at https://cdn.divine.video/bunny/*

Available endpoints:
- /bunny/video/:sha256 - Query by hash
- /bunny/video/guid/:guid - Query by GUID  
- /bunny/video/uploader/:pubkey - Videos by Nostr pubkey
- /bunny/events - Webhook events with filters
- /bunny/events/:guid - Events for specific video
- /bunny/recent - Recent uploads
- /bunny/failed - Failed encodings
- /bunny/processing - Currently processing

All tested and working in production. No authentication required for reads.

D1 database has two main tables:
- bunny_webhook_events - All webhook events from Bunny
- video_metadata - Current state for each video by SHA-256

Documentation in BUNNY_API.md covers all endpoints with examples.
