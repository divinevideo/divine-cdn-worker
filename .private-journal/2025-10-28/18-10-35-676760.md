## Blossom SDK Worker - Production Issues Fixed (2025-10-28)

### Critical Bugs Fixed

1. **500 Error on Video Uploads**
   - Location: `src/index.mjs:565`
   - Issue: `new BunnyUploadHandler()` missing `env` parameter
   - Fix: `new BunnyUploadHandler(env)`
   - Triggered when: Videos routed to BunnyStream (BUNNY_UPLOAD_DEST=bunny)

2. **Missing Signature Verification**
   - Location: `src/index.mjs:748-760` (verifyBlossomAuth)
   - Issue: Accepted ANY kind 24242 event without validating signatures
   - Fix: Implemented full NIP-01 verification with @noble/curves
   - Added: `verifyNostrSignature()` function using Schnorr/BIP-340

3. **POST Method Not Supported**
   - Location: `src/index.mjs:195` and line 65 (CORS)
   - Issue: Server only accepted PUT, client was sending POST
   - Fix: Accept both PUT and POST per Postel's Law

### Architecture Notes

**BunnyUploadHandler Pattern:**
- Constructor requires `env` to create BunnyStreamClient
- Stores `env` as instance variable in `this.env`
- Uses `_getClient()` lazy initialization pattern
- Methods also receive `env` as parameter (redundant but kept for compatibility)

**Upload Flow for Videos:**
1. `handleUploadBlob()` calls `selectUploadStrategy()`
2. Strategy checks `BUNNY_UPLOAD_DEST` env var
3. If "bunny", creates BunnyUploadHandler and initiates upload
4. BunnyUploadHandler creates BunnyStreamClient with credentials
5. Returns video ID and GUID for metadata storage

**Environment Variables:**
- `DEV_AUTH_MODE`: "false" in production, "true" for dev (secure by default)
- `BUNNY_STREAM_ENABLED`: "true" to enable BunnyStream integration
- `BUNNY_UPLOAD_DEST`: "bunny", "r2", or "dual" (routing strategy)
- `BUNNY_STREAM_ACCESS_KEY`: Secret for BunnyStream API
- `BUNNY_STREAM_LIBRARY_ID`: Library ID for video uploads

### Security Model

**Production (DEV_AUTH_MODE=false):**
- Full Schnorr signature verification
- Event ID validation
- SHA-256 hash verification for uploads
- Reject all invalid signatures

**Development (DEV_AUTH_MODE=true):**
- Can use simple `Authorization: Nostr pubkey=<hex>` format
- Skips signature verification (for testing only)
- Still validates event structure
