## Project Notes

CRITICAL BUG FOUND: The mp4Url being generated in src/index.mjs:667 is wrong. We're generating `https://{pullZone}/{videoId}/play.mp4` but BunnyStream's actual format is `https://{pullZone}/{videoId}/play_{resolution}p.mp4` (e.g., play_720p.mp4). The maximum fallback resolution is 720p. This needs immediate fix in both the code and the Flutter integration guide.
