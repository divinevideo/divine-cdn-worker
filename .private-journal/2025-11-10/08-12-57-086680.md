## Project Notes

BunnyStream MP4 fallback details:
- MP4 fallback must be enabled in library settings BEFORE upload
- Maximum fallback resolution is 720p
- Standard video encoding resolutions appear to be: 240p, 360p, 480p, 720p, 1080p, 1440p, 2160p
- MP4 fallback only goes up to 720p
- URL format: https://{pullZone}/{videoId}/play_{resolution}p.mp4
- Videos don't upscale - can't create 720p fallback from 480p source
- Rabble wants to default to 480p for the mp4Url
